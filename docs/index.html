Security is the architecture

Agents get tools. Never a blank check.

MCP scopes constrain credentials, WordPress capabilities constrain users, and exposure policy lets administrators decide which tools exist at all.

Read security policy →
A1

OAuth 2.1 + PKCE

Dynamic client registration, audience-bound tokens, rotating refresh tokens, and protected-resource discovery.

A2

Layered authorization

Read-only, editor, and administrator MCP scopes remain bounded by the associated WordPress user's actual capabilities.

A3

Strict inputs, safe outputs

Schema validation, SSRF controls, HTML sanitization, bounded queries, secret redaction, and explicit destructive-action confirmation.

A4

Governable surface

Disable individual tools or integration operations. Disabled capabilities disappear from discovery and fail closed on direct calls.

Up and running

Connect in three moves.

Install the release ZIP

Upload it in Plugins → Add New → Upload Plugin, then activate.

Create a scoped credential

Open Settings → Mindio Magic MCP and choose the smallest suitable scope.

Add the MCP endpoint

Use your site's REST endpoint and the generated bearer token.

mcp.config.json
{
  "mcpServers": {
    "mindio-magic-mcp": {
      "type": "http",
      "url": "https://example.com/wp-json/flatsome-mcp/v1/mcp",
      "headers": {
        "Authorization": "Bearer fmp_YOUR_KEY"
      }
    }
  }
}
